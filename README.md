# TFM_DRP_ESS11

Master's thesis project analysing determinants of right-wing populist voting in Europe using ESS11 survey data.

## Contents

- Construction of dependent variable (vote_drp)
- Data cleaning and recoding
- Linear probability models
- Robustness checks with country fixed effects
- Tables and descriptive statistics

## Software

- R
- tidyverse
- haven
- lmtest
- sandwich
